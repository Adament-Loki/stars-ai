
# v4.9.1 Safe Recovery

This build responds to Turn-1 corruption observed in the v4.9 playtest.

## Changes

### SaveAndSubmit
Known-good Stars!-generated `.x#` samples contain:

```
46 SaveAndSubmit
length = 4
payload = 01 01 05 19
```

The integrated writer had been synthesizing a zero-length type-46 block.
v4.9.1 now preserves the exact SaveAndSubmit block from each player's
known-good template.

### Research
Only directly observed encodings are emitted:

```
Electronics      0F 64
Biotechnology    0F 65
```

Energy, Weapons, Propulsion and Construction are skipped until controlled
Stars!-generated samples validate them.

### Colonization
The experimental native Colonize task introduced in v4.8 is disabled.
The strategy may still decide to colonize, but the native writer logs/skips
that order until a real Stars!-generated colony order is captured.

Normal scout/fleet movement remains enabled.

## Validation
Use a fresh seed and run exactly one turn first. Confirm all four generated
`.m#` files open normally in Stars!. Then try three turns.

Do not reuse files generated by the corrupt v4.9 run.
