
# v6.3 Current-Turn X Registration

The tool now treats an AI decision and an accepted Stars! order file as two
separate things.

## Current-turn X construction
Every `GAME.x#` is rebuilt for the current `.m#` turn:
- current game id/version/turn
- correct player
- file type 1 (X/order file)
- turnSubmitted flag set
- hostUsing/multipleTurns/gameOver cleared
- encryption salt preserved from the known-good bootstrap X
- current M unknown/shareware high flag bits preserved

## Fresh FileHash
The 17-byte FileHash is generated fresh every turn.
Its first uint16 equals the actual serialized order-stream length.

## SaveAndSubmit
The writer no longer invents a Type 46 block.
Controlled valid Stars! X files exist without it.
If the bootstrap template had Type 46 it is preserved; otherwise none is added.

## Pre-host registration barrier
The exact live `GAME.x#` must match the current M:
- game id
- turn
- player
- fileType=1
- submitted=true
- valid FileHash length

## Exact X archive
Before hosting, exact generated bytes are copied to logs:
`turn-001-player-01-GENERATED.x1`

This file survives even if Stars! consumes the live X.

## Post-host consumption barrier
A year advance is no longer enough to report success.
The exact live `GAME.x#` must also have been consumed/removed by Stars!.

If year advances but the X remains, the run is marked failed with:
`all_x_consumed=false`.
